# Murad Sharifov

**Artificial Intelligence · Robotics · Computer Vision**

I'm an M.S. student at Columbia Engineering, focused on AI, robotics, and perception. I'm interested in how visual algorithms interact with optics, sensors, and illumination, and how that imaging chain affects what robots can perceive.

Alongside my AI work, I build Java applications and Spring Boot backends.

## Current focus

- Computer vision and image classification
- Robotic perception and physical imaging systems
- Understanding model predictions through evaluation and visual inspection

## Recent machine-learning work

**[Traffic sign recognition](https://github.com/shmuradd/traffic-sign-recognition):** a PyTorch computer-vision project with frozen ResNet18 features, a trained neural classifier, validation on unseen physical signs, official test evaluation, and Grad-CAM inspection.

**Chest X-ray classification with ResNet18:** transfer learning, partial fine-tuning, class-level evaluation, decision-threshold analysis, and Grad-CAM heatmaps for inspecting predictions. The source repository is currently private.
